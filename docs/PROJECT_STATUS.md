## 1. 한 줄 요약

TILLY 프론트엔드는 아직 로그인·가입 화면과 API 기반 코드만 있고, 홈/기록/아카이브/인사이트/설정은 빈 화면(`PagePlaceholder`)이다. 디자인은 PC(1440px) 기준이며 홈·기록·아카이브·인사이트만 하이파이가 나왔다.
